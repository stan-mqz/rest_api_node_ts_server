# REST API Server

  

## 🌐 English


### Description

This is a REST API server built with Node.js, Express, and TypeScript. It provides a robust backend service with features including:

- PostgreSQL database integration with Sequelize ORM

- Swagger documentation

- CORS support

- Request validation

- Logging with Morgan

- Testing with Jest

- TypeScript support

  

### Installation

1. Make sure you have Node.js installed on your system

2. Clone the repository

3. Navigate to the server directory:

```bash

cd server

```

4. Install dependencies:

```bash

npm install

```

5. Create a `.env` file in the server directory with your environment variables

  

### Available Scripts

-  `npm run dev`: Start the development server with hot reload

-  `npm run build`: Build the TypeScript project

-  `npm run test`: Run tests

-  `npm run test:coverage`: Run tests with coverage report

  

### Development

To start the development server:

```bash

npm  run  dev

```

  

The server will start on the default port (check your .env file for configuration).
